TECHNICAL NOTES
- PNG format throughout.
- Decorative crack/fracture/rubble assets are standalone individual files with transparent backgrounds.
- UI icons are standalone individual files with transparent backgrounds and multitone coloration.
- Material sources are not guaranteed seamless; they are source materials for runtime sampling/cropping.
- Stairs as world semantics remain procedural/vector in implementation; ascend/descend here are UI action icons.
- Final SVG / Flutter-path vectorization of UI icons is a downstream implementation task.
